## Products

ServiceHub and Virtual Try-On are built for the Serbian market, so the apps and their pages are in Serbian.

### [Maestro ServiceHub](https://maestro-solutions.org/servicehub/)

An app for car repair and tire shops. Type a license plate and the vehicle's whole file opens: mileage, last service, history. Work orders print in one click, stored tire sets are found by shelf, and before the season the app tells the shop whom to call. Each workshop gets only the modules it uses and a database of its own.

<a href="https://maestro-solutions.org/servicehub/"><img src="https://maestro-solutions.org/servicehub/snimak-poster.webp" width="100%" alt="ServiceHub vehicle file for a Škoda Octavia with mileage, last service and next service" /></a>

### [Maestro Virtual Try-On](https://maestro-solutions.org/virtual-try-on/)

Virtual try-on for fashion web shops. On a product page, the shopper adds a photo and in about half a minute sees themselves wearing the item, with no account and without leaving the shop. The shop adds one script and a button to its product pages, and the same flow works on phone and desktop.

<a href="https://maestro-solutions.org/virtual-try-on/"><img src="https://maestro-solutions.org/virtual-try-on/demo-poster.webp" width="100%" alt="Virtual Try-On demo: one photo tried on with a dress, a blazer, a sweater and trousers, each processed in about 30 seconds" /></a>
