## Products

ServiceHub and Virtual Try-On are built for the Serbian market, so the apps and their pages are in Serbian.

### [Maestro ServiceHub](https://maestro-solutions.org/servicehub/)

An app for car repair and tire shops. Type a license plate and the vehicle's whole file opens: mileage, last service, history. Work orders print in one click, stored tire sets are found by shelf, and before the season the app tells the shop whom to call. Each workshop gets only the modules it uses and a database of its own.

### [Maestro Virtual Try-On](https://maestro-solutions.org/virtual-try-on/)

Virtual try-on for fashion web shops. On a product page, the shopper adds a photo and in about half a minute sees themselves wearing the item, with no account and without leaving the shop. The shop adds one script and a button to its product pages, and the same flow works on phone and desktop.

### Maestro CMS

Our own API-first CMS for the sites we build. Each client gets an isolated instance with its own database, edits content and business data without waiting for a developer, and cannot break the site's layout.

### AI assistants

- **[Mini Maestro](https://maestro-solutions.org/en/services/ai-document-assistant/)** searches a company's PDF, Word, Excel and TXT files, answers with sources and drafts new documents from approved company knowledge.
- **[AI Voice Agent](https://maestro-solutions.org/en/services/ai-voice-agent/)** answers the phone, books appointments and qualifies leads, then hands the call to a person when it should.

## Stack

<img src="https://skillicons.dev/icons?i=react,vite,tailwind,js,php,py,fastapi,mysql,postgres,redis,docker,nginx,linux,tauri,githubactions,figma&perline=8" width="480" alt="React, Vite, Tailwind CSS, JavaScript, PHP, Python, FastAPI, MySQL, PostgreSQL, Redis, Docker, nginx, Linux, Tauri, GitHub Actions, Figma" />

- **Front end:** React, Vite and Tailwind CSS, plus Tauri for the Mini Maestro desktop app.
- **Back end:** plain PHP 8 for ServiceHub, Virtual Try-On and Maestro CMS, and Python with FastAPI for Mini Maestro.
- **Data:** MySQL 8, PostgreSQL 16 with pgvector, and Redis.
- **AI:** document search over company files with embeddings, pgvector and OCR, speech-to-text with faster-whisper, and image models for virtual try-on.
- **Infrastructure:** our own Proxmox servers, Docker, nginx and Caddy, cPanel hosting and GitHub Actions.
